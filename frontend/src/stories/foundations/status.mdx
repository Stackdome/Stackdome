# Status system

Every domain state (stack, resource, release, health, addon, …) maps to one of
five `StatusVariant`s via `statusVariant(domain, state)` in
`src/components/branded/status-variant.ts`. Each variant is backed by a
semantic token triplet (`--*`, `--*-bg`, `--*-border`). Never map states to
colors ad hoc — add the mapping there.

## Example domain mappings

| Domain | State | Variant |
| --- | --- | --- |
| release | `Pending`, `InProgress` | pending |
| release | `Released` | ready |
| release | `Failed` | error |
| stack | `Ready` | ready |
| stack | `Progressing`, `Deleting` | pending |
| stack | `Failed`, `Degraded`, `Error` | error |
| generic | anything unrecognized | info |
| any | empty state | neutral |
