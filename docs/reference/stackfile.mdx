---
title: "Stackfile reference"
description: "The declared Stackfile schema for resources, builds, ports, environment values, secrets, addons, dependencies, and volumes."
---

A Stackfile is a YAML deployment definition consumed by `stackdome deploy`. Generate it with `stackdome init`, then run `stackdome validate` after every edit.

<Warning>
  The installed CLI is the execution authority. If this reference, the declared schema, and a release candidate differ, follow `stackdome validate` and the behavior of that release. The current release candidate does not map the schema's `stateful` key into the generated stack; do not rely on that key to change workload behavior.
</Warning>

## Complete example

```yaml
name: storefront

resources:
  web:
    image: nginx:latest
    ports:
      - name: http
        port: 80
        protocol: HTTP
        public: true
        subdomain: storefront
    env:
      APP_ENV: production
      CACHE_HOST: "{{ cache.host }}"
    secrets:
      storefront-api:
        API_KEY: api_key
    addons:
      storefront-db:
        type: postgres
        database: storefront
        superuser: false
        env:
          DATABASE_URL: "postgres://{{ username }}:{{ password }}@{{ host }}:{{ port }}/{{ database }}"
    volumes:
      - name: web-data
        path: /usr/share/nginx/html
    depends_on:
      - cache

  cache:
    image: redis:7-alpine
    ports:
      - name: redis
        port: 6379
        protocol: TCP

volumes:
  web-data:
    size: 1Gi
    access_mode: ReadWriteOnce
```

## Top-level properties

| Field | Type | Required and default | Example |
| --- | --- | --- | --- |
| `name` | string | Required, non-empty; no default. Must be unique within the project. | `storefront` |
| `resources` | map of resource name to resource object | Required with at least one entry; no default. | `web: { image: nginx:latest }` |
| `volumes` | map of volume name to volume definition | Optional; no volumes by default. | `web-data: { size: 1Gi }` |

Only the listed top-level keys are part of the declared schema.

## Resource properties

Each key under `resources` is the resource name. A resource must contain exactly one of `image` or `build`.

| Field | Type | Required and default | Example |
| --- | --- | --- | --- |
| `image` | string | Required when `build` is absent; no default. Mutually exclusive with `build`. | `nginx:latest` |
| `build` | build object | Required when `image` is absent; no default. Mutually exclusive with `image`. | `{ repo: https://github.com/acme/storefront.git }` |
| `ports` | array of port objects | Optional; no ports by default. | `[{ name: http, port: 8080, public: true }]` |
| `env` | map of string to string | Optional; no environment entries by default. | `{ APP_ENV: production }` |
| `secrets` | map of secret name to secret mapping | Optional; no secret connections by default. | `storefront-api: { API_KEY: api_key }` |
| `addons` | map of addon name to addon connection object | Optional; no addon connections by default. | `storefront-db: { type: postgres, env: { DB_HOST: "{{ host }}" } }` |
| `volumes` | array of volume mount objects | Optional; no mounts by default. Every name must exist in top-level `volumes`. | `[{ name: web-data, path: /data }]` |
| `depends_on` | array of strings | Optional; no dependencies by default. Every value must name another resource. | `[cache]` |
| `stateful` | boolean | Optional; schema default is `false`. The current release candidate does not map this key into the generated stack. | `true` |

## Build properties

| Field | Type | Required and default | Example |
| --- | --- | --- | --- |
| `repo` | string | Required and non-empty; no default. | `https://github.com/acme/storefront.git` |
| `branch` | string | Optional. Mutually exclusive with `tag` and `commit`. Although the schema describes `main`, the current CLI leaves an omitted revision unset so the server resolves the repository's default branch. | `main` |
| `tag` | string | Optional; no default. Mutually exclusive with `branch` and `commit`. | `v1.4.0` |
| `commit` | string | Optional; no default. Mutually exclusive with `branch` and `tag`. | `4b1c97a8f1d0c04366f8906c5bfa6f6fffe32a19` |
| `dockerfile` | string | Optional; defaults to `Dockerfile`. | `docker/Dockerfile.prod` |
| `context` | string | Optional; defaults to `.`. | `services/web` |

Specify at most one revision selector. When none is set, the release candidate asks the server to resolve the repository's default branch.

```yaml
resources:
  api:
    build:
      repo: https://github.com/acme/storefront.git
      branch: main
      dockerfile: services/api/Dockerfile
      context: services/api
```

## Port properties

| Field | Type | Required and default | Example |
| --- | --- | --- | --- |
| `name` | string | Required and non-empty; no default. | `http` |
| `port` | integer | Required; no default. Must be from `1` through `65535`. | `8080` |
| `protocol` | string enum | Optional; schema default is `HTTP`. Allowed values are `HTTP` and `TCP`. | `TCP` |
| `public` | boolean | Optional; defaults to `false`. | `true` |
| `subdomain` | string | Optional and non-empty when present; no default. Applies to a public port. | `api` |

A port name is also used in output accessors. With one port, use outputs such as `port`, `url`, `public_host`, and `public_url`. With multiple ports, append the port name, such as `url.http`.

## Environment properties

`env` is a map whose keys are environment variable names and whose values are strings. It is optional and has no entries by default.

```yaml
env:
  APP_ENV: production
  SELF_URL: "{{ self.public_url }}"
  CACHE_HOST: "{{ cache.host }}"
  CACHE_URL: "redis://{{ cache.host }}:6379"
```

Values can be:

| Form | Type and requirement | Example |
| --- | --- | --- |
| Literal | String; no default. | `APP_ENV: production` |
| Self output | String containing only one self reference. | `SELF_URL: "{{ self.public_url }}"` |
| Resource output | String containing one resource reference. | `CACHE_HOST: "{{ cache.host }}"` |
| Embedded resource template | String whose references all come from the same resource. | `CACHE_URL: "redis://{{ cache.host }}:6379"` |

Available resource outputs are `host`; port and URL outputs; and public host and URL outputs for public ports. `stackdome validate` checks output names against the referenced resource's ports.

## Secret mappings

`secrets` maps a Stackdome secret name to one or more environment-variable mappings. Each mapping value is the key inside the secret.

| Field | Type | Required and default | Example |
| --- | --- | --- | --- |
| Secret name | map key | Required for each mapping; no default. Resolved to a secret ID during deploy. | `storefront-api` |
| Environment mapping | map of environment variable name to non-empty secret key | At least one entry is required; no default. | `API_KEY: api_key` |

```yaml
secrets:
  storefront-api:
    API_KEY: api_key
    API_SECRET: api_secret
```

The Stackfile names secret keys; it does not contain secret values.

## Addon connections

`addons` maps an addon name to a connection object. Addon names are resolved to IDs during deploy.

| Field | Type | Required and default | Example |
| --- | --- | --- | --- |
| `type` | string enum | Required; no default. The declared schema supports `postgres`. | `postgres` |
| `env` | map of string to string | Required with at least one entry; no default. Values use addon output references. | `DB_HOST: "{{ host }}"` |
| `database` | string | Optional and non-empty when present; no default. Selects a database in the Postgres addon. | `storefront` |
| `superuser` | boolean | Optional; defaults to `false`. | `false` |

Postgres outputs are `host`, `port`, `database`, `username`, `password`, `sslmode`, `ca_certificate`, and `url`. Values may be direct references or templates:

```yaml
addons:
  storefront-db:
    type: postgres
    database: storefront
    env:
      DB_HOST: "{{ host }}"
      DATABASE_URL: "postgres://{{ username }}:{{ password }}@{{ host }}:{{ port }}/{{ database }}"
```

## Volume definitions and mounts

Top-level `volumes` defines storage. A resource's `volumes` array mounts that storage.

### Volume definition

| Field | Type | Required and default | Example |
| --- | --- | --- | --- |
| `size` | string | Required and non-empty; no default. Uses a quantity such as `500Mi` or `10Gi`. | `5Gi` |
| `access_mode` | string enum | Optional; defaults to `ReadWriteOnce`. Allowed values are `ReadWriteOnce`, `ReadWriteMany`, and `ReadOnlyMany`. | `ReadWriteMany` |

### Volume mount

| Field | Type | Required and default | Example |
| --- | --- | --- | --- |
| `name` | string | Required and non-empty; no default. Must match a top-level volume name. | `web-data` |
| `path` | string | Required and non-empty; no default. Must be an absolute container path. | `/var/lib/storefront` |

## Dependencies

`depends_on` is an optional array of resource names with no default entries. Each value must identify another resource in the same Stackfile; a resource cannot depend on itself.

```yaml
resources:
  api:
    image: ghcr.io/acme/storefront-api:1.4.0
    depends_on:
      - cache
  cache:
    image: redis:7-alpine
```

## Validate the file

```bash
stackdome validate --file stackfile.yaml
```

Validation checks the file available to the installed release candidate. Run it again whenever you change a field or upgrade the CLI.
