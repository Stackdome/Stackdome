Your coding agent can prepare the Stackfile, deploy the application, check that it is running, and return its public URL.

## Before the agent starts

The agent needs the repository, your Stackdome URL, and an API token. You create and revoke the token. The agent never needs your account password. See [authentication and API tokens](/reference/authentication).

Copy this and paste it into your agent:

```text
Fetch https://agents.stackdome.com and follow the instructions
```
